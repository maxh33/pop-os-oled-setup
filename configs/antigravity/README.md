# Antigravity (AGY) Configurations

Arquivos de referência e backup das configurações do Google Antigravity (AGY) no Pop!_OS.

## Conteúdo

- `GEMINI.md`: Espelho de `~/.gemini/config/GEMINI.md` contendo as regras globais de segurança, commits sem atribuição de IA, conventions e integração com RTK.
- `settings.json`: Espelho de `~/.gemini/antigravity-cli/settings.json` com configurações de permissão, tema e diretórios autorizados.

Para o guia completo de arquitetura e funcionamento, consulte [docs/25-antigravity-setup.md](../../docs/25-antigravity-setup.md).
